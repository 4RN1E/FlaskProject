# Flask Micro-API Project

## Description
A minimal Flask web API demonstrating RESTful design principles with two primary endpoints (`/hello` and `/data`) that support both GET and POST HTTP methods. This project showcases backend development fundamentals including JSON response formatting, proper HTTP status codes, input validation, and API testing.

Built as part of the Software Development & Implementation Research (SDIR) course at Florida International University, this project emphasizes AGILE development practices and professional API design patterns.

## Features
- ✅ RESTful API design with proper HTTP methods
- ✅ JSON request/response formatting
- ✅ Appropriate HTTP status codes (200 OK, 201 Created, 400 Bad Request)
- ✅ Input validation and error handling
- ✅ In-memory data storage
- ✅ Tested with Postman
- ✅ Clean, PEP-8 compliant code with documentation

## Technologies
- Python 3.8+
- Flask 3.0.0
- Postman (for testing)
